# News Writer 用户操作指南

适用版本：News Writer 1.0.0，Windows 10/11 x64。

News Writer 是一个新闻稿写作工作台：保存活动纪要、Prompt、新闻稿版本、批注、图片附件和任务记录，并在你明确操作后导出干净的 DOCX。正式支持 DeepSeek。

## 一、首次启动

1. 运行便携目录中的 `News Writer.exe`（保留整个目录结构，不要只复制或移动 exe）。
2. 打开「DeepSeek 认证」，输入自己的 API Key 并保存。
3. API Key 只保存在当前 Windows 用户的本机安全存储中，不写入项目、Prompt、导出文件或日志。

使用前请自备有效的 DeepSeek API Key 和网络。应用不需要额外安装 Node.js、Python、conda 或浏览器。

## 二、新建或打开项目

- **新建**：在欢迎页点击「新建项目」，输入名称、选择「学院新闻稿」或「其他新闻稿」，再选择保存目录。
- **打开**：在欢迎页点击「打开项目」，选择包含 `project.json` 的完整项目目录。

项目正被其他窗口或进程使用时，应用会提示项目锁；确认没有其他实例后，再按提示恢复过期锁。

## 三、准备活动纪要

在左侧「活动纪要」中直接编辑，或通过「文件 → 导入活动纪要」导入 `.md`/`.txt` 文件。

纪要尽量写清楚日期、时间、地点、举办或组织单位、参与人员、活动内容和新闻稿要求。事实检查只提供核对线索，不代替你证明事实。

编辑器会在停止输入约 1 秒后自动保存，也可点保存图标或按 `Ctrl+S` 立即保存；底部显示「纪要有未保存修改」时，先保存再开始下一步。

## 四、参考稿检索

底部「参考稿检索」开关默认开启。准备初稿 Prompt 时，应用会先保存纪要，再从随包只读知识库检索，把命中稿件的标题和节选加入 Prompt。

关闭开关后，本轮明确不使用参考稿。知识库是只读的，没有增删、扫描或重建入口；资源不可用时会如实标注，不影响继续准备初稿。

## 五、生成初稿

1. 点击「准备初稿 Prompt」。
2. 在「Prompt」标签查看内容和「事实检查」结果；有缺失项时回到纪要补充并保存，然后重新准备。
3. 如需修改 Prompt，先点击「编辑 Prompt」并确认风险提示；修改可能破坏事实约束和写作规范，责任由你承担。
4. 确认后点击「生成新版本」。

任务区只显示真实状态（准备中、处理中、已完成、失败、取消、超时），不显示虚假进度。任务进行中，纪要保存、批注、配置、导出和版本切换会被暂时禁用；可点击「取消任务」，但取消只停止本地等待，不保证服务端已停止或不会产生费用。

成功版本不可变；失败、取消或超时不会覆盖已有版本，也不会产生成功的空版本。

## 六、AI 二次审稿与续改

- **二次审稿**：在已有版本后点击「AI 二次审稿」，检查审稿 Prompt 后「生成新版本」，成功产生子版本。需要补充或更正的事实请先写回纪要，再重新准备 Prompt。
- **批注续改**：在最新版正文选中文字 →「为所选文本添加批注」→ 输入意见并保存；可用「编辑批注」「重新锚定」修改。点击「按照批注更新 Prompt」，检查后生成新版本。

批注永久属于其版本；续改时该版本批注会快照进 Prompt，新版本不自动继承。批注不会导出到 Word。

## 七、历史版本与分支

在资源栏「版本关系」查看版本树：点击任意版本查看历史稿；选择版本后「与最新版比较」查看差异；点「设为最新版」可回溯到历史版本。

「设为最新版」只移动最新版指针，不删除之后的版本；从历史版本继续生成会形成新的分支。

## 八、图片附件

在资源栏「图片」区管理新闻稿配图（最多 5 张，无图注）：

1. 点击「添加图片」选择 `.jpg`/`.png` 文件。应用会自动压缩（修正方向、最长边 2048 像素、输出 <1MB JPEG）并生成缩略图预览。
2. 使用上移/下移调整顺序，用删除按钮或「清空」移除图片。
3. 图片只作为项目附件保存，不进入纪要正文，也不会被当作事实来源。

任务进行中或项目归档时，图片区为只读。

## 九、导出 DOCX

1. 在「版本关系」选择要导出的版本（未选择时默认当前最新版）。
2. 点击「导出 DOCX」，选择目标位置并确认。
3. 在「导出记录」查看成功或失败。

导出的 Word 只包含新闻稿正文和已添加的图片（图片位于正文与落款之间、宽度对齐页面），不包含批注、Prompt、检索信息、问题清单或内部任务数据。导出失败不会修改已有版本。

## 十、归档、恢复与备份

在「项目」菜单选择「归档或恢复项目」。归档只改变项目状态，不删除版本，也不会把稿件加入知识库；归档项目为只读，恢复后可继续编辑。

关闭应用后复制整个项目目录即可备份。目录包含纪要、版本、批注、Prompt、任务、检索与导出记录；不包含 API Key、应用内置知识库或运行环境。不要只复制 `project.json`。

## 十一、常见问题

- **提示请先配置 API Key**：打开「DeepSeek 认证」重新保存；Key 只对当前 Windows 用户和本机有效。
- **提示 Prompt 已过期**：纪要、配置、检索结果、最新版或批注变化后会过期，选择「重新生成 Prompt」。
- **项目显示为只读**：检查是否已归档，通过「项目」菜单恢复。
- **任务失败/超时/取消**：按任务区的安全错误信息检查网络、Key 和配置后重试；已有成功版本不会被覆盖。
- **关闭项目时有未保存提示**：先保存纪要或 Prompt 草稿再关闭，否则未保存的编辑会丢失。

## 十二、交付给其他人使用

在开发机运行 `corepack pnpm package:dir` 生成 `release/win-unpacked`，把整个目录（或整体压缩）交给对方。对方解压后运行 `News Writer.exe`，配置自己的 API Key 即可使用；无需安装 Node.js、Python、conda 或浏览器。

不要只发送 exe，也不要发送源码、`node_modules`、测试产物或 QA 的 PDF/PNG/DOCX。当前没有安装包、自动更新和正式代码签名；未签名程序可能触发 Windows SmartScreen 提示，请通过可信的内部渠道交付。

把已有项目交给对方时，关闭应用后复制整个项目目录，对方需重新配置自己的 API Key。升级应用时替换完整便携目录即可，项目目录无需放进 `release/win-unpacked`；替换前先关闭应用并备份项目目录。
